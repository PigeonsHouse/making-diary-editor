# 製作日誌動画エディター

日々の製作記録を、VOICEVOXキャラクターの掛け合い動画にするWebエディターです。

詳細な仕様と実装方針は[設計.md](./設計.md)を参照してください。

## 起動

1. `.env.example`を`.env`へコピーし、必要なら`GEMINI_API_KEY`を設定します。
2. Docker Composeを起動します。

```bash
docker compose up --build
```

ブラウザで`http://localhost:3000`を開きます。同じLAN内の端末からは、ホストPCのIPアドレスとポート`3000`を指定します。

ローカルでアプリだけを開発する場合は、PostgreSQL、Redis、VOICEVOXを起動したうえで次を実行します。

```bash
pnpm install
pnpm dev
```

## 検証

```bash
pnpm typecheck
pnpm test
pnpm build
docker compose config
```

## 出したいコンテンツ

※ エディターのバージョンアップによりコンテンツは変わりえます。

- 今作りたいものリスト
  - リストを画面に出して、今週はこれに取り組んだ、先週に引き続き、今週からは…みたいな話をしたい
- 日誌(以下の構成を7日分)
  - イントロとして、裏で映像を見せつつ、日付を真ん中に出す
  - 日付カットアウト、以降日付は左上
  - 右上にその日の概要(サブタイトル)
  - 背景にはその日の作業の様子の動画・画像
  - 下半分には字幕の背景の矩形(微透明の黒、ちょっとだけ紺)
  - 矩形から顔と肩が見える程度で、画面端に一人づつ立ち絵を置く
  - セリフは基本同時に1人まで
    - ただしツッコミなど、2セリフ以上画面に出るケースもある
      - ツッコミセリフが終わるまで元セリフは表示し続ける
      - あるセリフを親に、オーダーを持つ子セリフがあり、子セリフがそれぞれ前のセリフ(0番目の子は親)に対し何秒食い気味に発話するかを指定できるイメージ
  - 動画や画像を出していないときの基本背景は白背景にグレーのグリッド
  - 1日に10〜20ラリー程度
    - これはシステムで担保するものではなくユースケースとしてのメモ
